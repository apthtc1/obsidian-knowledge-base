    Для копирования полного дерева файловых объектов в архив с условным
названием /backup.tar.gz необходимо выполнить следующую команду:
    sudo tar --xattrs --acls -czf backup.tar.gz \
        --exclude=/proc --exclude=/lost+found \
        --exclude=/backup.tar.gz \
        --exclude=/mnt \
        --exclude=/sys \
        --exclude=/parsecfs \
        /
    где: backup.tar.gz – название файла-архива.
    --exclude – Указывает, какие файлы и каталоги копировать не нужно.
    / – последний параметр указывает каталог, который нужно копировать (/ - корневой
каталог для полного копирования).
    Восстановление файлов из архива осуществляется с помощью следующей
команды:
    echo 1 | sudo tee /parsecfs/unsecure_setxattr
    sudo /usr/sbin/execaps -c 0x1000 -- tar --xattrs --xattrsinclude=security.{PDPL,AUDIT,DEF_AUDIT} --acls -xzf backup.tar.gz -C /
echo 0 | sudo tee /parsecfs/unsecure_setxattr
    где: backup.tar.gz – название файла архива
    -C / – параметр, указывающий, что перед началом разархивирования нужно
перейти в корневой каталог (корневой каталог «/»).
    Резервные копии образов файловой системы необходимо перенести на сервер
хранения данных (сервер NAS). Перенос по локальной сети необходимо выполнять с
помощью протокола SSH. Клиентская служба SSH входит в дистрибутив Astra Linux и
устанавливается по умолчанию. Для передачи образа файловой системы на удаленный
сервер необходимо выполнить следующую команду:
    sudo tar -cvpz / | ssh <IP-адрес сервера NAS> "( cat > ssh_backup.tar.gz )"
    где: ssh_backup.tar.gz – название файла архива на удаленном сервере.
    Восстановление файловой системы от удаленного сервера на восстанавливаемый
АРМ выполняется с помощью следующей команды:
    cat ssh_backup.tar.gz | ssh <IP-адрес клиента> "tar -xvpzf - -C /tmp"
    где: ssh_backup.tar.gz – название файла архива на удаленном сервере.
    <IP-адрес клиента> – IP-адрес АРМ, на котором необходимо восстановить
файловую систему.
    -C /tmp – каталог, в который будут распаковываться файлы резервной копии.
