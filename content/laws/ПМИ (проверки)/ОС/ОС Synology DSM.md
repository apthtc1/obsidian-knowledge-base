Проверка встроенных механизмов безопасности ОС Synology DSM

| №   | **Наименование испытаний<br><br>**                                                                    | **Действия**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | **Критерий**                                                                                                                                                                                                                                                                                                          | **Продолжительность проверки** |
| --- | :---------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------- |
| 1   | Проверка идентификации и аутентификации пользователей                                                 | •	Авторизоваться в ОС Synology DSM по WEB-интерфейсу;<br>•	Открыть меню «Панель управления», выбрать пункт «Пользователь и группа» → «Пользователь».<br>                                                                                                                                                                                                                                                                                                                                       | •	В системе присутствует выделенная локальная учётная запись администратора.                                                                                                                                                                                                                                          |                                |
| 2   | Проверка парольной политики                                                                           | •	Авторизоваться в ОС Synology DSM по WEB-интерфейсу;<br>•	Открыть меню «Панель управления», выбрать пункт «Пользователь и группа» → «Дополнительно».<br>                                                                                                                                                                                                                                                                                                                                      | •	Убедиться, что параметры политики паролей настроены согласно ОРД<br>ООО «Сахалинская Энергия».<br>                                                                                                                                                                                                                  |                                |
| 3   | Проверка ограничения количества неуспешных попыток входа                                              | •	Авторизоваться в ОС Synology DSM по WEB-интерфейсу;<br>•	Открыть меню «Панель управления», выбрать пункт «Безопасность» → «Учётная запись». Проверить значения параметров ограничения количества неуспешных попыток входа;<br>•	Проверить применение политик - под учётной записью пользователя выполнить попытки входа в ОС Synology DSM без пароля / с использованием неверного пароля в количестве   превышающем требуемое пороговое значение ввода правильного пароля до блокировки.<br> | •	Убедиться, что параметры ограничения количества неуспешных попыток входа настроены согласно ОРД<br>ООО «Сахалинская Энергия»;<br>•	Убедиться, что по итогу попыток входа в ОС без пароля / с использованием неверного пароля происходит блокировка учётной записи с выводом информационного сообщения на экран.<br> |                                |
| 4   | Проверка защиты аутентификационной информации в процессе её ввода (скрытие символов при вводе пароля) | •	Завершить сеанс пользователя в ОС Synology DSM;<br>•	В окне авторизации ОС Synology DSM в WEB-интерфейсе ввести имя учётной записи и пароль.<br>                                                                                                                                                                                                                                                                                                                                             | •	Убедиться, что при вводе пароля аутентификационная информация не отображается в открытом виде.                                                                                                                                                                                                                      |                                |
| 5   | Проверка блокировки сеанса пользователя при бездействии                                               | •	Авторизоваться в ОС Synology DSM по WEB-интерфейсу;<br>•	Открыть меню «Панель управления», выбрать пункт «Безопасность» → «Безопасность».<br>•	Оставить WEB-интерфейс ОС Synology DSM в режиме ожидания, подождать установленное время;<br>                                                                                                                                                                                                                                                  | •	Убедиться, что параметры блокировки сеанса пользователя при бездействии ОРД<br>ООО «Сахалинская Энергия».<br>•	По истечению времени ожидания произойдёт разрыв сессии<br>                                                                                                                                           |                                |
| 6   | Проверка синхронизации времени от сервера единого времени                                             | •	Авторизоваться в ОС Synology DSM по WEB-интерфейсу;<br>•	Открыть меню «Панель управления», выбрать пункт «Информационный центр» → «Общие».<br>                                                                                                                                                                                                                                                                                                                                               | •	Убедиться, что в параметрах сервера NTP указан сервер единого времени.                                                                                                                                                                                                                                              |                                |
| 7   | Проверка регистрации событий ИБ                                                                       | •	Провести авторизацию в ОС Synology DSM, используя учётную запись администратора;<br>•	Произвести выход из сессии;<br>•	Попытаться зайти под учётной записью администратора с некорректным паролем;<br>•	Зайти под учётной записью администратора с корректным паролем;<br>•	Открыть меню «Центр пакетов», выбрать пункт «Центр журналов» → «Журналы». Посмотреть журнал событий «Подключение».<br>                                                                                           | •	Убедиться в наличии событий входа в учётную запись и событий отказа входа в учётную запись.                                                                                                                                                                                                                         |                                |
| 8   | Проверка поступления событий в SIEM-систему                                                           | •	Проконтролировать, что события безопасности, полученные в ходе проверок, поступают в систему мониторинга и управления событиями ИБ MaxPatrol SIEM.                                                                                                                                                                                                                                                                                                                                           | •	События поступают в MaxPatrol SIEM.                                                                                                                                                                                                                                                                                 |                                |
