Проверка встроенных механизмов безопасности ОС Windows

| №   | **Наименование испытаний<br><br>**                                                                    | **Действия**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | **Критерий**                                                                                                                                                                                                                                                                                                          | **Продолжительность проверки** |
| --- | :---------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :----------------------------- |
| 1   | Проверка идентификации и аутентификации пользователей                                                 | •	Авторизоваться в ОС Windows под учётной записью администратора;<br>•	Открыть меню «Пуск», выбрать пункт «Панель управления», перевести в режим отображения элементов «Мелкие значки»;<br>•	Выбрать «Учётные записи пользователей» → «Управление учётными записями пользователей».<br>                                                                                                                                                                                                                                                                                                                                                          | •	В системе присутствует выделенная локальная учётная запись администратора.                                                                                                                                                                                                                                          |                                |
| 2   | Проверка парольной политики                                                                           | •	Авторизоваться в ОС Windows под учётной записью администратора;<br>•	Нажать сочетание клавиш на клавиатуре «Win» + «R», в открывшемся окне ввести «secpol.msc» и нажать клавишу «Enter»;<br>•	Перейти в меню «Параметры безопасности» → «Политики учётных записей» → «Политика паролей» («Security Settings» → «Account Policies» → «Password Policy»).                                                                                                                                                                                                                                                                                        | •	Убедиться, что параметры политики паролей настроены согласно ОРД<br>ООО «Сахалинская Энергия».                                                                                                                                                                                                                      |                                |
| 3   | Проверка ограничения количества неуспешных попыток входа                                              | •	Авторизоваться в ОС Windows под учётной записью администратора;<br>•	Нажать сочетание клавиш на клавиатуре «Win» + «R», в открывшемся окне ввести «secpol.msc» и нажать клавишу «Enter»;<br>•	Перейти в меню «Параметры безопасности» → «Политики учётных записей» → «Политика блокировки учётных записей» («Security Settings» → «Account Policies» → «Account Lockout Policy»);<br>•	Проверить применение политик - под учётной записью пользователя выполнить попытки входа в ОС Windows без пароля / с использованием неверного пароля в количестве   превышающем требуемое пороговое значение ввода правильного пароля до блокировки.<br> | •	Убедиться, что параметры ограничения количества неуспешных попыток входа настроены согласно ОРД<br>ООО «Сахалинская Энергия»;<br>•	Убедиться, что по итогу попыток входа в ОС без пароля / с использованием неверного пароля происходит блокировка учётной записи с выводом информационного сообщения на экран.<br> |                                |
| 4   | Проверка защиты аутентификационной информации в процессе её ввода (скрытие символов при вводе пароля) | •	Завершить сеанс пользователя в ОС Windows;<br>•	В окне авторизации ОС Windows ввести имя учётной записи и пароль.<br>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | •	Убедиться, что при вводе пароля аутентификационная информация не отображается в открытом виде.                                                                                                                                                                                                                      |                                |
| 5   | Проверка блокировки сеанса пользователя при бездействии                                               | •	Авторизоваться в ОС Windows под учётной записью администратора;<br>•	Нажать сочетание клавиш на клавиатуре «Win» + «R», в открывшемся окне ввести «secpol.msc» и нажать клавишу «Enter»;<br>•	Перейти в меню «Параметры безопасности» → «Локальные политики» → «Параметры безопасности» («Security Settings» → «Account Policies» → «Password Policy»), посмотреть параметр «Интерактивный вход в систему: предел простоя компьютера» («Interactive logon: Machine inactivity limit»);<br>•	Оставить компьютер в режиме ожидания, подождать установленное время.<br>                                                                           | •	Убедиться, что параметры блокировки сеанса пользователя при бездействии ОРД<br>ООО «Сахалинская Энергия»;<br>•	По истечению времени ожидания произойдёт блокировка.<br>                                                                                                                                             |                                |
| 6   | Проверка синхронизации времени от сервера единого времени                                             | •	Авторизоваться в ОС Windows под учётной записью администратора;<br>•	Щёлкните по часам на панели задач, посмотрите настройки времени в ОС Windows.<br>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         | •	Убедиться, что в параметрах сервера NTP указан сервер единого времени.                                                                                                                                                                                                                                              |                                |
| 7   | Проверка регистрации событий ИБ                                                                       | •	Провести авторизацию в ОС Windows, используя учётную запись администратора;<br>•	Произвести выход из сессии;<br>•	Попытаться зайти под учётной записью администратора с некорректным паролем;<br>•	Зайти под учётной записью администратора с корректным паролем;<br>•	Открыть журнал регистрации событий в консоли «Просмотр событий», перейти в раздел «Журналы Windows\Безопасность».<br>                                                                                                                                                                                                                                                   | •	Убедиться в наличии событий входа в учётную запись и событий отказа входа в учётную запись.                                                                                                                                                                                                                         |                                |
| 8   | Проверка поступления событий в SIEM-систему                                                           | •	Проконтролировать, что события безопасности, полученные в ходе проверок, поступают в систему мониторинга и управления событиями ИБ MaxPatrol SIEM.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | •	События поступают в MaxPatrol SIEM.                                                                                                                                                                                                                                                                                 |                                |
